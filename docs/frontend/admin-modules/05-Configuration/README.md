# 05 - Configuration

> **User Journey Stage**: The Controls
> **Goal**: Manage global application settings.

## 📖 Overview
Global switches and policy configurations that affect the entire platform.

## 🧩 Submodules
1.  **Projects (`FRONTEND_ADMIN_CONFIG_PROJECTS.md`)**:
    - Feature Flags.
    - Global Maintenance Mode.
    - Project CRUD operations.
    - Knowledge documents management.
    - Assignment rules configuration.

2.  **Policy Management (`FRONTEND_ADMIN_POLICIES_MAIN.md`)**:
    - List and search Privy policies.
    - Create and update policies.
    - Manage policy rules.
    - View policy details and configuration.

## 🎨 UX Guidelines
- **Caution**: UI should emphasize that changes here affect ALL users.
