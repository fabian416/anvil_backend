# 01 - Admin Overview

> **User Journey Stage**: The Pulse
> **Goal**: High-level visibility into system performance and security.

## 📖 Overview
This is the landing page for the Admin Console. It answers the question: **"Is the system healthy and performing?"**

## 🧩 Submodules
1.  **Chat Analytics (`FRONTEND_ADMIN_DASHBOARD_CHAT.md`)**:
    - Usage volume, Agent Performance, and Cost Tracking.
2.  **Security Dashboard (`FRONTEND_ADMIN_DASHBOARD_SECURITY.md`)**:
    - Vulnerability scan results and security health status.

## 🎨 UX Guidelines
- **Dashboard Layout**: Grid-based layout with "Sparkline" cards at the top.
- **Priority**: Security "Critical" alerts must take precedence over everything else.
