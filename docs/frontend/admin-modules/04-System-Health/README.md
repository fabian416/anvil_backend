# 04 - System Health

> **User Journey Stage**: The Engine
> **Goal**: Monitor low-level infrastructure metrics.

## 📖 Overview
Technical monitoring for DevOps and Site Reliability Engineering (SRE) tasks.

## 🧩 Submodules
1.  **Metrics (`FRONTEND_ADMIN_SYSTEM_METRICS.md`)**:
    - CPU/RAM usage.
    - Database connectivity.
    - API Latency.
    - Transaction metrics.
    - Wallet metrics.
    - User activity metrics.

2.  **Stats (`FRONTEND_ADMIN_SYSTEM_STATS.md`)**:
    - System statistics overview.
    - Active conversations count.
    - Total messages count.
    - Agent usage statistics.

3.  **Retry System (`FRONTEND_ADMIN_RETRY_MAIN.md`)**:
    - Monitor service status.
    - Enable/disable services.
    - Manage circuit breakers.
    - View retry metrics and analytics.

## 🎨 UX Guidelines
- **High Density**: This view allows for more dense technical data (logs, charts) than the business dashboards.
