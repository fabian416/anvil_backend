# 07 - Settings & Support

> **User Journey Stage**: The Configuration
> **Goal**: Personalize the experience and resolve issues.

## 📖 Overview
The administrative backend of the user's profile. This is where preferences are tuned and help is sought.

## 🧩 Modules
1.  **Profile & Preferences**:
    - **Main** (`FRONTEND_USER_SETTINGS_MAIN.md`).
    - **Profile** (`FRONTEND_USER_SETTINGS_PROFILE.md`): Identity and risk settings.
    - **Security** (`FRONTEND_USER_SETTINGS_SECURITY.md`): Keys and 2FA.
2.  **Subscription (`FRONTEND_USER_SETTINGS_SUBSCRIPTION.md`)**:
    - Billing and plan management (Stripe).
3.  **Support**:
    - **Main** (`FRONTEND_USER_SUPPORT_MAIN.md`).
    - **FAQs** (`FRONTEND_USER_SUPPORT_FAQ.md`).
    - **Tickets** (`FRONTEND_USER_SUPPORT_TICKET.md`).

## 🎨 UX Guidelines
- **Control**: Users should feel in complete control of their data.
- **Accessibility**: Design for ease of use, especially in Support flows.
- **Confirmation**: Any destructive action (Account deletion, Unsubscribing) needs friction.
