# 06 - DeFi Advanced (Ultra)

> **User Journey Stage**: The Power User
> **Goal**: Execute complex, high-risk/high-reward strategies.

## 📖 Overview
The "Ultra" suite is for sophisticated users. It exposes atomic transaction capabilities like Flash Loans and Arbitrage execution.

## 🧩 Modules
1.  **Flash Loans (`FRONTEND_USER_DEFI_ULTRA.md`)**:
    - Borrowing without collateral for single-block transactions.
2.  **Arbitrage Discovery**:
    - Finding price discrepancies across DEXs.

## 🎨 UX Guidelines
- **Risk Warnings**: Strict "High Risk" modals and disclaimers.
- **Simulation**: Users MUST be able to simulate strategies (and see PnL) before executing.
- **Professional Mode**: Data density should be higher here than in the Core dashboard.
