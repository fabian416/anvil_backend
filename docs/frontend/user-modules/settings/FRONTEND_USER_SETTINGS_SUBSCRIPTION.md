# Module: Settings Subscription

**Route**: `/settings/subscription`
**Auth Required**: Yes
**Package**: `user/settings`

## 1. Overview
Manage Anvil Pro subscription.

### Key Features
- **Plan Status**: Free / Pro.
- **Upgrade Flow**: Payment via Stripe or Crypto.
- **Invoices**: View past payments.

## 3. API Integration
`GET /api/v1/subscription/plans`
`POST /api/v1/subscription/checkout`
