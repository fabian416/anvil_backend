# 04 - Intelligence & AI

> **User Journey Stage**: The Brain
> **Goal**: Synthesize data into decision-making power using AI.

## 📖 Overview
This is the differentiating factor of the Anvil platform. It combines specific AI Agents with deep data visualization to help users make informed financial decisions.

## 🧩 Modules
1.  **AI Chat (`FRONTEND_USER_CHAT_MAIN.md`)**:
    - The central interface for Intent Detection and Agent Squads.
    - **WebSocket** (`FRONTEND_USER_CHAT_WEBSOCKET.md`): Real-time streaming protocol.
    - **Analytics** (`FRONTEND_USER_CHAT_ANALYTICS.md`): Usage and cost tracking.
2.  **Graph Visualization (`FRONTEND_USER_HOME_GRAPH.md`)**:
    - D3.js powered knowledge graph of token relationships.
3.  **Protocol Comparison (`FRONTEND_USER_HOME_COMPARISON.md`)**:
    - Side-by-side analysis of DeFi opportunities.

## 🎨 UX Guidelines
- **Conversational UI**: The interface should feel like a partner, not a CLI.
- **Latency Masking**: Use "Thinking..." states and optimistic UI updates.
- **Visual Evidence**: Always back up AI claims with charts or data citations.
