## 🚀 DEPLOYMENT INSTRUCTIONS

### **Quick Deploy:**

```bash
# 1. Configure secrets
kubectl create secret generic defi-chat-secrets \
  --from-literal=database-url=postgresql://... \
  --from-literal=redis-url=redis://... \
  --from-literal=jwt-secret=... \
  --from-literal=oneinch-api-key=... \
  -n production

# 2. Deploy to production
./scripts/deploy.sh production

# 3. Verify deployment
curl https://api.defi-chat.example.com/health
kubectl get pods -n production

# 4. Monitor
kubectl logs -f deployment/defi-chat -n production
```
